Journal Application

Journal Application is a backend project built using Java and Spring Boot that allows users to create, manage, update, and delete personal journal entries. The project demonstrates the core concepts of Spring Boot development, including REST APIs, layered architecture, dependency injection, and database integration with MongoDB.

Features
Create new journal entries
View all journal entries
Update existing entries
Delete journal entries
RESTful API implementation
MongoDB database integration
Layered architecture using:
Controller layer
Service layer
Repository layer
Exception handling and clean project structure
Tech Stack
Java
Spring Boot
Spring Web
Spring Data MongoDB
MongoDB
Maven
Project Structure
Controller → Handles HTTP requests and API endpoints
Service → Contains business logic
Repository → Handles database operations
Model/Entity → Defines journal entry data structure
Database

The project uses MongoDB as the database for storing journal entries.

API Operations

The application supports basic CRUD operations:

POST → Create a journal entry
GET → Fetch journal entries
PUT → Update a journal entry
DELETE → Remove a journal entry
Purpose of the Project

This project was built to practice and understand backend development using Spring Boot and MongoDB while implementing a clean layered architecture commonly used in real-world applications.
